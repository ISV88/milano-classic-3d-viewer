# MILANO Classic — 3D-просмотр

Текущая модель: **Classic v9**. Статический просмотрщик: вращение, масштаб, виды спереди/сзади/сбоку/сверху/снизу, переключение фона и скачивание GLB.

Файлы сайта расположены в корне. Для GitHub Pages: ветка main, каталог /(root). Файл .nojekyll отключает обработку статических файлов через Jekyll.

## Модель

assets/classic.glb — самодостаточный GLB со встроенными текстурами. Красный и дно соответствуют рабочей v9. Габарит 50 × 86 × 21 мм — условный QS; размеры Classic и производственная конструкция ещё не подтверждены. Это презентационная реконструкция.

## Обновление

Заменить assets/classic.glb и assets/poster.png, увеличить параметр ?v= в index.html и номер версии на странице. После загрузки изменений в main GitHub Pages обновит сайт.

## Локальный просмотр

Запустить `python -m http.server 8765` из этого каталога и открыть http://localhost:8765/. Открытие index.html напрямую через file:// может блокировать загрузку модели.

Библиотека @google/model-viewer 4.4.0 сохранена локально в assets/model-viewer.min.js. Сведения о сторонних компонентах — THIRD_PARTY_NOTICES.md. Исходные макеты и Blender-файлы в репозиторий не включены.
